# Password Generator

A command-line Python program that generates a password based on a length provided by the user.

## Features

- Generates passwords of a user-selected length
- Includes uppercase letters
- Includes lowercase letters
- Includes digits
- Includes symbols
- Randomizes the final character order

## How to Run

Make sure Python is installed, then run:

```bash
python password_generator.py
```

Enter a password length of four or more when prompted.

## Current Status

This is an early learning project. Input validation and password-generation security will be improved in future versions.
